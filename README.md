This program writes a single-line roast aimed squarely at the entrant's own AI agent, teasing an agent whose memory is summarized so frequently that its childhood has been reduced to a bullet list. The line is 83 characters long, which sits comfortably inside the required gate of 1 to 200 characters, and the program writes it as plain UTF-8 with no extra newline, so the output is byte-identical on every run.

## Run it

```sh
python3 main.py
```
